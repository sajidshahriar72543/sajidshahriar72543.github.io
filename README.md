# Personal Academic Website

This repository contains the source code for my personal academic website.

The website serves as a central hub for my research activities, publications, academic background, professional experience, and curriculum vitae. It is designed to be lightweight, responsive, and easy to maintain using only HTML and CSS.

## Features

* Academic profile and biography
* Research publications and ongoing projects
* Curriculum Vitae (CV)
* Responsive design for desktop and mobile devices
* Links to Google Scholar, ORCID, GitHub, LinkedIn, and Email

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## Inspiration

The overall layout and concept of this website were inspired by the Academic Pages project:

https://github.com/academicpages/academicpages.github.io

This website is **not a fork, clone, or direct replica** of Academic Pages. It is a custom implementation built from scratch using plain HTML and CSS, with a simpler structure tailored to my own academic and professional needs.

## Using This Repository

If you would like to create your own academic website, feel free to fork this repository and customize it for your needs:

```bash
git fork https://github.com/sajidshahriar72543/sajidshahriar72543.github.io
```

Please replace all personal information, publications, images, and links with your own content before deployment.
